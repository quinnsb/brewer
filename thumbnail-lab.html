Thumbnail Lab

Directions for the image on the LinkedIn featured link, all built from the footer palette. Each one is drawn at 1200 by 627, the size LinkedIn crops a link preview to, then scaled down here. Large fits one to a row at whatever width the window allows. Switch to LinkedIn size to see them all at the width they actually appear, and turn on crop guides to check what survives if a surface squares the image off.

Set two. Cropped repeat

After the St Paul's Cathedral system. The name set far too large, repeated down the frame with each row offset, so it runs off both edges and gets cut mid-letter. A hard split crosses the whole thing and the two colors swap sides. The letterforms line up exactly across that seam because both sides are the same type block, clipped rather than redrawn.

Set three. The same two cuts across the palette

H, J and K are all the same drawing with the colors swapped, so here they are against twelve pairings the site already carries. These grids hold their own size, three across, because the point is comparing them rather than blowing one up. The ratio under each tile is measured off the rendered pixels, not written down, so it stays honest. Anything under 3 to 1 is flagged, since that is the floor for large text.
